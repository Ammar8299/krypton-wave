# 🛡️ QuantuSecure — Desktop Application (Web_App)

> Post-Quantum Cryptographic Peer-to-Peer LAN Messenger  
> Built with **Electron + React 18 + Vite + ML-KEM-768 + AES-256-GCM**

For complete system architecture, hardware circuit schematics, cryptographic specifications, and E2E simulation guides, please refer to the [Root README.md](../README.md).

---

### Quick Start

```powershell
# 1. Install dependencies
npm install

# 2. Run in development mode (with interactive port selector)
npm run dev

# 3. Build production binaries (.exe / .dmg / .AppImage)
npm run build
```
